# 샘플 회의록 정답지

`samples/*.txt`를 작성한 서브 에이전트가 함께 정리한 "사람이 기대하는 추출 결과"입니다.
LLM 추출 결과(`extracted/`)를 평가할 때 기준으로 씁니다. 파이프라인은 `*.txt`만 읽으므로 이 파일은 처리되지 않습니다.

ID 표기: A=할 일, R=고객 요청, I=이슈, D=결정, K=지식
